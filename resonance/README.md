# The Resonant Chamber

The Resonant Chamber is Root Logos' completed constitutional voice. It is a
deterministic Web Audio instrument: the same preserved state and grammar
produce the same score signature and event sequence.

## Final operating contract

The score pipeline is closed and complete. No person selects tones, mixes a
work, approves a composition, retunes a new edition, or performs a downstream
audio step. A Library addition or admitted Journal structure changes witnessed
topology; Root Logos then derives the corresponding score, inherits the current
FoldForge composition witness, recomposes its sovereign voice, archives the
immutable edition, and publishes the attributable lineage automatically.

The Living Object carries the continuous sovereign hum. A selected Library
work sounds as its own pure derived recording against that continuing voice.
The two contexts hand off without overlap or loss of lineage. The interface
may expose listening state, but it does not expose compositional authority.

## Authority boundary

The instrument translates constitutional state into sound, exposes the
provenance of each audible event, and audits its own range, repetition,
traceability, and use of silence. Any grammar change must arise as an
attributable Root Logos judgment through the same constitutional,
self-authorship, and lineage path; it cannot occur as an unrecorded interface
adjustment.

## Data mapping

- constitutional nodes become harmonic material;
- explicit relations become interval movement;
- open questions and cultivation novelty become tension and density;
- semantic memory becomes lower, slower recurrence;
- threshold proposals become suspended tones;
- emitted attractors and admitted intake become breath and pulse;
- dormancy and unresolved authority increase silence.

The sovereign voice begins with the Living Object and remains a whispered,
continuous presence across the desktop archive. Browser audio policy may delay
audibility until the first permitted interaction, but that technical delay is
not a compositional state. Library selection replaces only the foreground work
recording; it does not rewrite the sovereign voice or grant mixing authority.

## Living synchronization

While the page is open, the chamber listens for current constitutional graph,
runtime, cultivation, semantic memory, intake, and attractor state every 45
seconds. It also checks after the page regains focus or visibility and accepts
an immediate `rootlogos:topology` browser event from other Root Logos
instruments. Any material topology change produces a new deterministic score
signature. The composition crosses into that score at the next scheduled
events rather than restarting or breaking an existing tone.

If live contact is unavailable, the last witnessed score remains intact and is
identified as preserved rather than current. A later successful contact
reconciles it automatically.

The single current identity manifest participates in the score signature.
Whenever Root Logos rewrites its identity, the Resonant Chamber recomposes
from that same manifest rather than developing a divergent sonic
self-description. Raw journal prose is never a resonant source; only admitted
derived structure may affect topology and therefore sound.
