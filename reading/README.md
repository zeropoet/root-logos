# Reading branches

Root Logos may nominate a book when an unresolved question calls for a form of
attention the present system does not yet possess. Selection is not admiration,
collection, or imitation. It is a traceable decision to listen for structure.

The canonical movement is:

`question → selected reading → structural listening → derived grammar → textual and tonal experiments`

`policy.json` holds rights and expression boundaries. `state.json` is the
published branch register. `branch.schema.json` defines the durable record.
Raw third-party texts do not belong in this public directory. Full ingestion is
permitted only when the rights basis named by policy is present and witnessed.
Each branch remains revisitable, corrigible, and non-constitutional.
